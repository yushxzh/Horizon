## [AI 设计可行噬菌体基因组，合成生物学再获突破](https://www.schneier.com/blog/archives/2026/08/ai-is-learning-to-write-genetic-code.html) ⭐️ 8.0/10

**原标题**: [AI Is Learning to Write Genetic Code](https://www.schneier.com/blog/archives/2026/08/ai-is-learning-to-write-genetic-code.html)

研究人员使用两个 AI 模型，以感染大肠杆菌的ΦX174 噬菌体为模板，生成了完整且可行的噬菌体基因组。他们从约 70 万个设计中挑选出 285 个，合成 DNA 后确认能产生有活性的噬菌体。 这是 AI 驱动生物设计的一个里程碑，表明机器学习不仅能预测或分析基因序列，还能生成有功能的遗传密码。该成果对合成生物学和生物安全具有双重用途影响，既可能加速有益的工程应用，也可能被滥用。 这些模型生成了约 70 万个候选设计，研究人员从中挑选出 285 个最有希望的进行合成。基准是ΦX174，一种研究充分的单链 DNA 病毒，其基因组于 1977 年首次被测序，也是第一个由合成寡核苷酸在体外组装完成的基因组。

rss · Schneier on Security · 8月21日 16:51

**背景**: 噬菌体是一类感染并在细菌内部复制的病毒，是地球上最丰富和多样化的生物实体之一。自 1920 年代以来，一些国家已将其用作抗生素的替代品。ΦX174 专门感染大肠杆菌，在分子生物学中历史悠久，例如 1977 年 Fred Sanger 团队首次测序的 DNA 基因组就是它。

## [研究发现“请简洁”指令可让 LLM 输出成本降约 1.5 倍](https://www.reddit.com/r/MachineLearning/comments/1vulfei/does_telling_an_llm_to_be_concise_actually_save/) ⭐️ 8.0/10

**原标题**: [Does telling an LLM to &quot;be concise&quot; actually save you money? We measured it across 9 models. Compressing the output can save you money and keep accuracy, compressing the input prompt does not. \[R\]](https://www.reddit.com/r/MachineLearning/comments/1vulfei/does_telling_an_llm_to_be_concise_actually_save/)

一项覆盖九款 LLM 的新研究发现，要求模型输出更简短的回答可将成本平均降低约 1.5 倍（最高 3 倍），同时保持准确率。相反，压缩输入提示会使成本最高增加 96%，并降低准确率。 由于输出 token 通常比输入 token 更贵，这为 API 用户提供了一个简单且不依赖模型的成本优化手段。研究还验证了提供商推出“简洁输出风格”（如 Claude Code）的趋势，表明在用户自行控制提示时确实能省钱。 该研究在五个短答案数据集、一项十一语言输出测试和一项摘要测试中，评测了 GPT-4o、GPT-5.4、Claude Haiku 4.5、Claude Sonnet 4.6、Qwen2.5-VL-7B、Qwen3.5-9B、DeepSeek-R1-Distill、Gemma-4-E4B 和 Kimi-K2.6 等模型。值得注意的是，约一半情况下，即使缩短后的输出正确，其文本也不再与模型不受约束时的推理一致；如果只关心最终答案，这通常是可以接受的。

reddit · r/MachineLearning · /u/ibubbles34 · 8月21日 16:38

**背景**: LLM API 成本由 token 数量决定，且提供商通常对输出 token 的定价高于输入 token。提示压缩旨在缩短输入上下文同时保留语义，但这项研究表明，通过指令压缩输出才是更有效的成本杠杆。这一趋势也体现在 Claude Code 等工具中——它最近新增了 Concise 输出风格，在保持同样工程能力的前提下默认让回答变短。

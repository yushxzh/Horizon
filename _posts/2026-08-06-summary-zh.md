## [Deno 发布 Celld：自托管分布式 Durable Objects 运行时](https://github.com/denoland/celld) ⭐️ 8.0/10

**原标题**: [Celld: Self-hosted, distributed Durable Objects](https://github.com/denoland/celld)

Deno 发布了 Celld，一个用于自托管分布式 Durable Objects 的开源运行时。每个 Celld 节点都内嵌 V8，可以执行 Wrangler bundles，而 durable object 的状态存储在 SQLite 中，并复制到你拥有的 S3 兼容存储桶中。 Durable Objects 将计算和存储组合成一种有状态的 serverless 模型，但此前一直被绑定在单一提供商（Cloudflare）上。Celld 打破了这种锁定，让开发者可以把自己的基础设施、本地机器或 spot 实例上部署同样的抽象，这可能会扩大有状态 serverless 架构的采用范围。 每个 Celld 节点都内嵌 V8 并使用 isolates，因此空闲成本极低；整个集群通过一个共享的 S3 兼容存储桶来协调，存储部署包、cell 状态和较小的所有权记录。Deno 团队将其构建为一个不依赖 deno\_core 的全新运行时，并且能够执行为 Cloudflare Workers 编写的 Wrangler bundles。

hackernews · calvinfo · 8月5日 16:50 · [社区讨论](https://news.ycombinator.com/item?id=49185430)

**背景**: Durable Object 是 Cloudflare 在 2020 年首次推出的一种特殊 serverless Worker，它将计算与存储结合在同一个对象中。每个对象都有自己的 SQLite 数据库，按名称寻址，并且会自动在首次被请求的地理位置附近预置。Celld 将该模式应用到自托管部署中，使用 S3 兼容存储桶进行复制和协调，使开发者能够在托管提供商之外运行 Durable Objects。

## [KARR 汽车报警器漏洞可让黑客解锁 200 万辆车](https://www.schneier.com/blog/archives/2026/08/vulnerabilities-in-car-anti-theft-device.html) ⭐️ 8.0/10

**原标题**: [Vulnerabilities in Car Anti-Theft Device](https://www.schneier.com/blog/archives/2026/08/vulnerabilities-in-car-anti-theft-device.html)

加州大学圣地亚哥分校的研究人员发现，KARR Security System（KARR 安全系统）这一售后汽车报警器中存在漏洞，该系统据估计已安装在美国超过 200 万辆汽车上。位于蓝牙范围内的攻击者可以远程解锁汽车、关闭警报、鸣笛、闪烁车灯，甚至禁用点火系统。 这一点很重要，因为超过两百万辆汽车存在同一个安全漏洞，附近的黑客可以完全破坏汽车的防盗保护，甚至让发动机瘫痪，影响财产安全和人身安全。这也凸显出汽车生态系统中许多售后物联网设备的安全防护仍然十分薄弱。 根本原因是单个设计缺陷：每个 KARR 设备都使用相同的身份验证密钥，并且该密钥以明文形式存储在 KARR 智能手机应用中。2026 年 7 月 20 日发布了固件补丁，但必须通过官方应用将补丁交付到车辆模块；仅更新手机或车载信息娱乐系统无法修复此漏洞。

rss · Schneier on Security · 8月5日 09:42

**背景**: KARR Security System 是一种售后防盗和 GPS 找回设备，主要通过汽车经销商销售。由计算机科学教授 Aaron Schulman 领导的研究团队发现，该缺陷影响了近十年的安装案例。由于攻击通过蓝牙进行，黑客只需靠近汽车即可，无需特殊硬件。这一案例延续了安全研究人员揭露联网汽车配件身份验证薄弱的大趋势。
